захиалгыг авч төлөх дүнг тооцно. Хүснэгт болон хамгийн их

### Оролт
1. Хүний тоо: 5–20.
2. Хоолны нийт үнэ: 1–1000000 төгрөг.
3. Үйлчилгээний хураамж: 0–100000 төгрөг.
4. Хүн бүрийн захиалга: 0–нийт үнэ.

Захиалгуудын нийлбэр хоолны нийт үнэтэй тэнцэх ёстой.
Зөрвөл бүх захиалгыг дахин оруулна.

### Тооцоолол
Үйлчилгээний хураамжийг захиалгын үнэд хувь тэнцүүлэн хуваарилна.

cumulative = тухайн хүн хүртэлх захиалгын нийлбэр
allocated = бүхэл_хэсэг(cumulative × fee / total)
service[i] = allocated - previous
pay[i] = order[i] + service[i]

Хуримтлагдсан дүнгээр бодож, нийт хураамжийг төгрөгийн
үлдэгдэлгүй хуваарилна. Бүхэлчилсний зөрүү нь хүний
дарааллаас хамааран хуваарилагдана.
